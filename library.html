An Introduction to Sanctuary Club

sanctuary-club.uk is so much more than just a website.

It has been designed so that it is easy to use and so that all members can contribute just as much or as little as they wish.

If you only want to enjoy the Studio, get to know what’s going on and see useful information, enter using What’s On / Library and the wxyz Access Code.

But if you want to make use of all the Club has to offer, for privacy and security reasons you will need to set up a Personal PIN. You will then be able to enjoy full use of all the website facilities

If you need any help doing this, the Club’s Website Helpers will be only too happy to assist.

Nobody but you will know your household Personal PIN.

You decide just how much of your personal contact information to share. Entering your email address will enable you to receive messages intended for all members from the Club Committee and Residents Association Panel.

The members’ database is protected by the website’s privacy and security arrangements.
