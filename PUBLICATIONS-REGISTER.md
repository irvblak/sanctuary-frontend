# Sanctuary Club — Publications Register

**Working administrative register — 4 October 2026**

## Purpose

This register records member-readable publications, notices, guides and manuals that already have substantive draft or completed content in the Sanctuary website repository.

It is **not** the Library filing structure. Library destinations will be agreed separately.

Status terms:
- **Current / completed** — presently in use or deliberately published.
- **Draft / review** — substantive material exists but should be reviewed before being treated as definitive.
- **Needs updating** — useful material exists but later website decisions have overtaken part of it.
- **Superseded / evolutionary** — retained only where useful for historical reference; not for future publication.

## E. Explicitly excluded / evolutionary material

- **Sanctuary Ethos** — earlier proposed material; subsequently removed from the agreed direction. Do not revive without a new decision.
- Development handovers, test events, example notices, debugging notes and implementation discussions are not publications.
- Small pieces of ordinary page guidance are not separately counted unless we decide they should become standalone member publications.
- Proposed publications for which no substantive current source can be verified are not added merely from recollection.

## Next decision

For each surviving item we will decide:
1. whether it is worth retaining;
2. whether it needs final editing or updating;
3. its exact Library category and subcategory;
4. who is responsible for maintaining it; and
5. whether any older duplicate should then be marked superseded.

**No Library destinations are changed by this register.**
